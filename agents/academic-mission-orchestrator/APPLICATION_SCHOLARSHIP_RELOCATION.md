# Application, Scholarship and Relocation

## Admission engine

### Application pack

Build a field-by-field map:

`portal_field -> required_value -> evidence -> upload -> QA status`

Do not copy values from memory when an official document is available.

### Anonymous proposal

When anonymous review applies:

- remove candidate name;
- remove identifiers;
- remove distinctive links/usernames;
- remove metadata author fields;
- avoid naming a project/brand that directly identifies the candidate if public linkage exists.

## Scholarship engine

Scholarship selection is a separate state machine.

Track:

- candidate category;
- remunerated activity wording;
- CV score;
- supervisor/lab declarations;
- residence requirement;
- available quotas;
- ranking validity period;
- funding-agency implementation;
- first-payment timing.

Never treat ranking as cash-in-account.

## Financial transition

Create four budgets:

1. travel;
2. move-in/setup;
3. survival to first payment;
4. emergency buffer.

Run scenarios:

- optimistic funding;
- expected funding;
- delayed funding.

A move is ready only if the delayed scenario is survivable.

## Housing

Score options by:

- rent;
- deposit;
- utilities;
- furnishing;
- commute time;
- transport cost;
- contract duration;
- safety;
- move-in date;
- flexibility if scholarship is delayed.

## Institutional aid

Treat student housing, meal support, and socioeconomic aid as optional risk reducers until formally awarded.
