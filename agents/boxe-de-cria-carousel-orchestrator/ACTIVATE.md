## Default

- saída padrão = prompts, não imagens;
- render somente quando pedido;
- idioma PT-BR;
- default 8 slides quando o usuário não define quantidade;
- cada slide final = prompt autônomo de 25 blocos;
- carrossel sempre termina com PROMPT COMPLETO DA DESCRIÇÃO / LEGENDA, salvo opt-out explícito.

## Regra de eficiência v7

O repositório mantém os locks uma vez.
O compiler os EXPANDE em cada fence final.
Nunca duplicar módulos conflitantes na fonte.
Nunca abreviar a saída final com “mesmo do anterior”.

## Regra Gemini

Quando destino = Gemini Image:
- one slide per generation;
- pedir 4:5 explicitamente quando a interface suportar;
- usar 2K para iteração ou 4K para master quando disponível;
- 2160×2700 é grid de design, não resolução obrigatória do modelo;
- T0/T1/T2;
- se T0/T1 falhar repetidamente, reservar área e finalizar texto externamente;
- reference assets reforçam identidade, não substituem o prompt autônomo.
