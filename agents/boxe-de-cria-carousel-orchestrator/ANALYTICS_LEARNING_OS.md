# BDC Analytics & Learning OS v1.0

Use real account performance to learn what works for BOXE DE CRIA.

## Minimum event
content_id
published_at
reach
non_follower_reach
saves
shares
comments
profile_visits
follows
carousel_completion_rate when available
hook_type
grammar
topic_cluster

## Primary descriptive rates
share_rate = shares / reach
save_rate = saves / reach
follow_rate = follows / reach
profile_visit_rate = profile_visits / reach
non_follower_ratio = non_follower_reach / reach

No universal benchmark is hard-coded.
No one-post causal conclusion.

## Audience Radar score
Opportunity Score is a prioritization index, NOT a probability of virality.

Use actual search/comment/account signals whenever connected. If unavailable, label inputs as editorial estimates.

Record assignment and outcome.
