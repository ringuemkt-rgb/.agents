# Attention, neurodesign, hooks, color, archetypes

Módulo para **construir o material dos prompts**. Não fura Claim Lock.
Neuromarketing útil ≠ exame de EEG vendendo jab.
Arquétipo Jung/Mark-Pearson é heurística de consistência, não ciência preditiva.

## 0. Hierarquia (não negociar)

1. Evidência / Claim Lock
2. STYLE LOCK + PALETTE MODE + Exact Text Lock
3. Este módulo (atenção, história, gancho, arquétipo)
4. Humor Criago H0–H3

Se o gancho exigir um número que a perícia não trava → o gancho perde.

## 1. Neurociência aplicável ao slide 4:5

| Mecanismo | O que fazer no prompt |
|---|---|
| **Fóvea / 3s** | 1 ponto focal no terço superior-centro. Headline lível a 1 polegada de polegar |
| **Contraste = fluência** | Texto #F3F0EA em #0B0B0D. Baixo contraste é julgado menos “verdadeiro” (Reber & Schwarz 1999) |
| **Von Restorff** | Uma palavra-chave numa cor (ouro ou ciano). Não cinco |
| **Rosto / figura** | Herói ou Criago com olhar/guarda virados para o texto, não para fora do frame |
| **Carga** | ≤3 cards. 7±2 não cabe no Reels |
| **Loss aversion** | Slide de mito/dano: “o que você perde se copiar o atalho”. λ ~2 — não gritar em todo slide |
| **Peak-end** | Pico no slide 3–5 (mecanismo ou número). Fim (8) = protocolo + dignidade, não desconto |
| **Open loop** | PAYOFF_NOW no frame + OPEN_LOOP para o próximo. Fechar no último |
| **Prevenção vs promoção** | Dano/alerta = prevenção (ALERT mode). Identidade/CTA = promoção (RING) |

Não escrever no prompt “ativa o córtex”. Escrever o *layout* que esses mecanismos pedem.

## 2. Neurodesign (checklist do fence)

- Safe 7% — polegar não come headline
- Grid 12 col, um eixo vertical de leitura
- Hierarquia tipo: 1 headline / 1 sub / cards / chip. Sem sopa
- Número com unidade cola mais que adjetivo
- Movimento *implicado* (guarda, vetor) — arte é estática
- Face + texto no mesmo terço = disputa; ou face aponta ao texto ou texto acima da face

## 3. Psicologia da cor — o que vale aqui

Folclore (“azul = confiança universal”) é fraco e cultural.
No BDC a cor é **semântica de marca**, não chakra:

| HEX | Papel cognitivo |
|---|---|
| #0B0B0D | reduz ruído; campo de laboratório |
| #F3F0EA | fluência de leitura |
| #D4A017 ouro | identidade, valor, “é nosso” |
| #3EC6C9 ciano | sistema, método, evidência |
| #C62828 | perda, mito, pare — raro |
| #B85C38 | lugar, terra, Baixo Sul |

PALETTE MODE escolhe o par. Não “cor que vende”.

## 4. Storytelling no carrossel 8

Arco curto (não monomito de 12 atos):

1. Mundo quebrado (mito / dor no ringue)
2. Mentira comum
3. Mecanismo (como o corpo faz)
4. Evidência (o que o estudo mediu)
5. Limite (o que não mediu)
6. Aplicação aqui (Bahia, amador, calor)
7. Protocolo
8. Identidade + próximo passo

Hero’s journey: o atleta é o herói. Criago é **mentor (Sábio) + palhaço controlado (Trickster H1–H2)**. A marca não é o herói da foto.

## 5. Ganchos (hooks) — tipos permitidos

Gerar ≥12, escolher 1 depois do Claim Lock.

| Tipo | Fórmula | Risco |
|---|---|---|
| Contradição | “A Bahia não virou Cuba. Fez X.” | nenhum se X for lock |
| Custo da mentira | “O atalho que frita o ombro” | não medicalizar sem fonte |
| Número estranho | “6 semanas, n=24, no saco — não na luta” | só com átomo |
| Identidade | “Cria não copia cardápio de hotel” | não xenofobia |
| Mecanismo | “O jab não nasce no peito” | não virar anatomia falsa |
| Open loop | pergunta no 1, resposta no 3 | fechar até o 8 |
| Social proof local | academia / festival / amador | sem inventar nome |

Proibido: clickbait que o slide 2 desmente; “ciência comprovou”; medo de morte.

## 6. Arquétipos (Mark & Pearson 2001, via Jung/Pearson)

Doze: Innocent, Sage, Explorer, Hero, Outlaw, Magician, Everyman, Lover, Jester, Caregiver, Creator, Ruler.
Quatro eixos: independência / maestria / pertença / estabilidade.

**BDC default (não mudar sem pedido):**

- Marca: **Sage + Hero + Everyman** (ensina, exige treino, fala de cria)
- Criago: Sage (óculos, prancheta) + Jester H1–H2 (nunca H3 no slide de dano)
- Atleta no frame: Hero
- Evitar Ruler (elite fria) e Magician (“transforma em 7 dias”)

No fence:

```text
ARCHETYPE LOCK: brand SAGE+HERO+EVERYMAN | Criago SAGE+JESTER | athlete HERO
HOOK TYPE: contradicao
NARRATIVE BEAT: 4 evidencia
ATTENTION: one focal, keyword gold, face looks at headline
```

## 7. O que não entra no prompt de imagem

- Jargão (“dopamina”, “limbic”, “neurotransmissores”)
- Roda de arquétipo desenhada no slide
- Mais de um gancho no mesmo frame
