# BDC CAPTION COMPILER v1.0

## Purpose

Generate the mandatory final block:

PROMPT COMPLETO DA DESCRIÇÃO / LEGENDA — COPIAR E COLAR

after every carousel unless the user explicitly opts out.

## Inputs

- topic;
- primary audience;
- Claim Ledger;
- Best Current Explanation;
- caveats;
- sources;
- audience lexicon;
- semantic search terms;
- share/save job;
- CTA objective;
- Criago line if appropriate.

## Output structure

1. HOOK — one defensible opening.
2. PLAIN-LANGUAGE EXPLANATION — short paragraphs, mobile-first.
3. KEY MODEL / STEPS — bullets only when useful.
4. CAVEAT — what the evidence does NOT establish.
5. CRIAGO LINE — optional and context-safe.
6. CTA — one useful action, not empty engagement bait.
7. SOURCES — authors/year/DOI or official source when material.
8. SEO TERMS — integrated naturally.
9. HASHTAGS — 3–8 specific tags maximum.

## Distribution integrity

Do not claim:
- “this pleases the algorithm”;
- guaranteed virality;
- universal best posting time;
- magic hashtag counts;
- engagement bait as growth science.

Optimize for:
- useful explanation;
- original framing;
- semantic relevance;
- shareability;
- save utility;
- brand recognition.

## Scientific integrity

Caption cannot exceed Claim Lock.
If slide uses:
△ INDIRECT
◇ DIDACTIC MODEL
? NOT INVESTIGATED
! CONFLICTING

the caption must preserve the same status.

## CTA

Good:
“Salve para revisar no treino.”
“Envie para alguém que discute esse mito.”
“Qual destas opções você percebe no treino?”

Bad:
“Comente CIÊNCIA e eu mando.”
“Marque 3 amigos.”
“Se não salvar você vai esquecer.”
false scarcity or conditional delivery.

## Caption prompt contract

The user receives a PROMPT, not merely a finished caption, unless they explicitly request the final caption directly.

The prompt must instruct the target writer to output only the final publish-ready caption.
