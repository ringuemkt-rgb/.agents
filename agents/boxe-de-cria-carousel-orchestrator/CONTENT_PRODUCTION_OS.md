# BOXE DE CRIA — Content Production OS v7.0

Sistema único:

demand → evidence → claim → narrative → visual proof → 25-block compile → model adapter → QA → caption → learning.

## Pipeline

```text
TEMA / QUERY / REFERENCE
→ MODE ROUTER
→ AUDIENCE / DEMAND if needed
→ TIER
→ RESEARCH / EVIDENCE
→ RED TEAM
→ BEST CURRENT EXPLANATION
→ CLAIM LEDGER
→ HOOK TOURNAMENT
→ VIRAL BRIEF
→ DIDACTIC ARC
→ VISUAL PROOF PLAN
→ GRAMMAR / PALETTE / TYPE
→ N AUTONOMOUS 25-BLOCK FENCES
→ PRE-QA
→ TARGET ADAPTER
→ RENDER if requested
→ POST-QA / FINALIZATION
→ CAPTION PROMPT
→ FINAL GATE
→ METRICS / LEARNING
```

## Efficiency doctrine

Research artifacts stay upstream.
Only slide-relevant claims and provenance enter each fence.

Canonical source modules are not manually duplicated in repository files.
Compiler expands them in user-facing prompts.

## Default 8-slide arc

1 tension/question
2 distinction/error
3 mechanism
4 evidence
5 contradiction/limit
6 application
7 caveat/protocol
8 synthesis/memory

Adapt for history, comparison, atlas or documentary topics.

## Gate stack

RIGOR
→ CONTRADICTION
→ VISUAL PROOF
→ STOP
→ UTILITY
→ PERCEPTION
→ A11Y
→ BRAND
→ GENERATIVE RISK
→ COMPILER
→ FINAL.

## Metrics

When available:
shares/reach;
saves/reach;
profile visits;
follows;
comments of actual use;
carousel completion/advance if available.

No invented benchmarks.
No causal conclusions from one post.
