# Deterministic Finalization v1.0

Use generative models for hero, atmosphere and materiality.
Use deterministic layers for critical typography, exact data, DOI/source, counters and official logo whenever generative risk is HIGH.

## Routes
G1_IN_MODEL — low/medium risk.
G2_FINALIZATION_SAFE — high text/data/brand/anatomy risk.

Runtime helpers:
- src/dataviz/flat-svg.ts
- src/finalization/svg-text-layer.ts

Never let a generative model silently change a numerical value.
