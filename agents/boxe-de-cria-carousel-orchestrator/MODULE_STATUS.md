# BOXE DE CRIA Carousel Orchestrator — Module Status v5.1

## Purpose

Prevent conflicting instructions by classifying every repository file as:

- **AUTHORITY** — may define current behavior;
- **ENGINE** — active specialized subsystem;
- **SUPPORT** — helper/reference, cannot override authority;
- **COMPATIBILITY** — legacy knowledge kept for backward compatibility;
- **ARCHIVE** — historical audit/change record only.

If a SUPPORT/COMPATIBILITY file conflicts with ACTIVATE / SKILL / PROMPT_PROTOCOL_FIXED, the higher authority wins.

## No-conflict doctrine

1. User current instruction wins.
2. ACTIVATE/SKILL define behavior.
3. Engines define specialized logic.
4. PROMPT_PROTOCOL_FIXED defines slide output.
5. GEMINI_PRODUCTION adapts the output without shortening it.
6. Support files cannot create a new visual canon.
7. Legacy files cannot change version, prompt count or render law.
