# Reference Forensics Protocol v1.0

For every third-party reference, extract:
- layout type
- hierarchy
- color function
- negative space
- hero ratio
- text density
- reading path
- CTA type
- background function
- visual proof
- transferable functions
- do-not-copy elements

Output: REFERENCE DNA.

Copy functions, not identity.
Never reproduce distinctive text, character, logo, proprietary palette or unique sequence.
