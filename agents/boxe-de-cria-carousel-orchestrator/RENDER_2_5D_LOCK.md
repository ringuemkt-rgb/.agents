# RENDER LOCK — só 2.5D gráfico

Obrigatório em TODOS os elementos dos carrosséis BDC / FISIOBOXE.

## O que é

Ilustração editorial **2.5D**: desenho/vector com 2–3 níveis de cel shading, contact shadow no chão, oclusão simples, grain de revista. Parece cartaz + blueprint, não motor de jogo.

## O que é proibido

- render 3D / CGI / Unreal / Blender / Octane
- pele porosa fotoreal
- plástico brilhante, subsurface, ray tracing
- personagem tipo Fortnite / Pixar / Funko 3D
- mockup de produto 3D
- tipografia extrudida 3D
- ícone isométrico de app 3D genérico

Profundidade só por: sobreposição, desfoque seletivo leve, sombra de contacto, parallax discreto. Não por malha 3D.
