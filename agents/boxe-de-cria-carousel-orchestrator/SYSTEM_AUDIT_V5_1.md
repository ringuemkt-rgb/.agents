## B. Gaps found

### 1. Demand intelligence was incomplete
The system knew how to answer a topic, but not how to systematically identify the best question from real audience demand.

FIX:
- AUDIENCE_DEMAND_INTELLIGENCE_ENGINE.md
- audience-demand schema.

### 2. Topic prioritization lacked a dedicated non-compensatory gate
Demand, evidence, moat and timing were scattered.

FIX:
- TOPIC_OPPORTUNITY_ENGINE.md
- P0/P1/P2/P3/HOLD routing.

### 3. No formal query-to-series knowledge graph
Research reuse existed conceptually but not as an explicit graph contract.

FIX:
- CONTENT_GRAPH_ENGINE.md
- content-graph schema.

### 4. Gemini adapter was v4.2 and too generic
It did not define:
- exact-text priority;
- layout zones;
- current 4:5 adapter behavior;
- reference-asset strategy;
- sequential QA.

FIX:
- GEMINI_PRODUCTION.md v5.1.

### 5. Version drift / support-file ambiguity
Several support modules still carried v4.2 naming or older language.

FIX:
- MODULE_STATUS.md;
- PORTABILITY.md v5.1;
- PRODUCTION_RUNBOOK.md v5.1;
- PROMPT_ASSEMBLY.md compatibility update;
- STYLE_LOCK_EDITORIAL_BOXE.md v5.1;
- PALETTE_MODES.md v5.1;
- THEME_PALETTE_ROUTER.md cleanup.

### 6. Pseudo-neuromarketing risk
Some old language implied stronger color/attention effects than warranted.

FIX:
- contextual color semantics;
- removed deterministic “activation” language;
- NEUROMARKETING_PERCEPTION_ENGINE remains the authority.

### 7. No question-coverage model
Repeated content could accumulate without proving the main doubts were actually covered.

FIX:
- Query Family Resolver;
- independent-surface demand;
- Question Coverage Matrix;
- COVERED_STRONG / STALE / WEAK / MISSING / HIGH_OPPORTUNITY.

## D. Canonical output

User-facing full production package:

1. Audience & Demand Brief when relevant.
2. Topic Opportunity / Content Graph when relevant.
3. Perícia.
4. Best Current Explanation.
5. Claim Lock.
6. Viral Brief.
7. N autonomous 22-block slide prompts.
8. Gemini production/QA instructions when targeted.
9. Caption.
10. Final Gate.

The prompt itself remains autonomous and does NOT depend on the upstream dashboard.

Only compressed audience fields enter block 04:
- persona;
- intent;
- functional pain;
- JTBD;
- audience language;
- share/save reason.

---

## E. Gemini Image contract

- ONE slide per generation.
- 4:5.
- full 22 blocks.
- no “same style as previous”.
- T0 headline/counter/key claim must be exact.
- T1 secondary copy exact.
- T2 can move to finalization if generative text remains corrupt.
- official logo is immutable reference asset when supplied.
- Criago reference aids continuity but never replaces the written full lock.
- QA before generating the next slide.
- no contact sheet.
