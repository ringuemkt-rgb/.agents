# BDC TOPIC OPPORTUNITY ENGINE v1.0

## Missão

Priorizar pautas sem confundir popularidade, rigor e valor estratégico.

Não existe “score científico de viralidade”. Este módulo usa uma rubrica editorial transparente.

---

## 1. Inputs

Recebe:
- Audience & Demand Intelligence;
- freshness;
- competitor gap;
- BDC expertise moat;
- evidence availability;
- owned analytics quando disponíveis;
- content graph;
- calendário/eventos quando pertinentes.

---

## 2. Opportunity dimensions

Avaliar separadamente 0–3:

- DEMAND SIGNAL
- PAIN INTENSITY
- QUESTION CLARITY
- BDC EXPERTISE MATCH
- EVIDENCE DEPTH
- COMPETITOR GAP
- DISTINCTIVENESS
- SAVE UTILITY
- SHARE UTILITY
- TIMELINESS
- SERIES POTENTIAL
- VISUAL TEACHABILITY
- PRODUCTION COST

0 = fraco/ausente
1 = baixo
2 = bom
3 = forte

É rubrica editorial; não publicar o número como “probabilidade”.

---

## 3. Non-compensatory gates

Um tema NÃO sobe só porque tem demanda.

### Evidence gate
Se exige claim de saúde/performance e evidência não sustenta → reformular.

### Brand gate
Se BDC não tem perspectiva própria → baixa prioridade.

### Safety gate
Se o tema incentiva prática perigosa sem contexto → bloquear/reformular.

### Originality gate
Se seria apenas copiar trend → não publicar.

---

## 4. Priority classes

### P0 — BREAKING / HIGH VALUE
Precisa resposta rápida + alta relevância + BDC consegue explicar com segurança.

### P1 — CORE
Grande dor/dúvida + forte expertise + boa evidência + potencial de série.

### P2 — SUPPORT
Útil, mas secundário.

### P3 — LIBRARY
Evergreen de autoridade; publicar quando houver espaço.

### HOLD
Demanda existe, mas:
- evidência insuficiente;
- formato errado;
- timing ruim;
- risco alto;
- falta dado atual.

## 7. Theme families to dominate

Não usar como lista fixa; serve de mapa inicial.

### Técnica
jab, direto, cruzado, base, pivô, defesa, distância, timing, clinch.

### Fisiologia
gás, fadiga, pacing, potência, força, recuperação, sono.

### Biomecânica
transferência de força, cadeia cinética, base, quadril, estabilidade.

### Segurança
concussão, mão/punho, ombro, cervical, sparring.

### Neuro/percepção
antecipação, reação, visão, atenção, aprendizagem motora.

### TEA
sensorial, previsibilidade, comunicação, adesão, ambiente, benefícios/limites.

### História
escolas soviética/cubana/mexicana, vale-tudo, Luta Livre, SAMBO, boxe brasileiro.

### Compra/decisão
luva, bandagem, saco, equipamento, academia.

### Treinador
progressão, feedback, erros, carga, segurança.

---

## 8. Recommendation rule

Tema recomendado deve responder:
- por que este público precisa disso?
- por que agora?
- por que BDC?
- qual pergunta real?
- há evidência suficiente?
- qual formato ensina melhor?
- qual próximo nó da série?

Se uma dessas respostas for vazia, o tema ainda não está pronto.
