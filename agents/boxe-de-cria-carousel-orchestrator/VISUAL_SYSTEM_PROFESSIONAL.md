## 5. Typography System

### Display
Anton / Archivo Black / equivalent ultra-heavy condensed.
Use only for short headlines, numbers, large labels.

### Reading
Inter / Montserrat / equivalent highly legible sans.
Use for body, cards, source, labels, scientific notes.

Maximum:
- two functional font families;
- no script;
- no extruded/3D type;
- no all-caps paragraph blocks;
- no condensed body paragraphs.

Recommended final 1080×1350 visual sizes:
- cover headline: 96–132 px;
- internal headline: 72–96 px;
- subheadline: 42–54 px;
- hero number: 100–180 px;
- card title: 36–44 px;
- body: 34–40 px;
- labels: 30–36 px;
- source/footer: 28–32 px.

Hierarchy must be visibly different, not three near-identical sizes.

## 13. Template Library

One visual grammar per slide.

### CINE_COVER
Purpose: stop scroll + open loop.
Weight: ~65% visual / 35% type.
Use: one headline, at most one subheadline, one hero, one swipe cue.

### CLIPBOARD
Purpose: paper / method / study deconstruction.
Use: paper card + 2–3 cards for design, sample, outcome + “what it did not measure”.

### FLAT_CHART
Purpose: quantitative data.
Use: one principal chart + one takeaway + one caveat/source.
No 3D. No truncated misleading axes.

### SPLIT
Purpose: A×B, myth×measure, late×early.
Use: one axis of comparison at a time; max three comparison axes.

### STACK_STEPS
Purpose: drill / protocol / action.
Use: 3–5 steps, numbered, visually sequential.

### HUB
Purpose: multi-factor system.
Use: one central node + max five functional nodes.

### PATH
Purpose: causal/temporal/process story.
Use: one readable path. Any causal arrow requires Claim Lock support.

### ISO_FLOW
Purpose: spatial flow only when truly helpful.
Use sparingly; never as a default pseudo-3D infographic.

Never mix multiple grammars into “infographic soup”.

## 16. Scientific / Evidence Visual Law

Every material claim must map to:
- a visual;
- a label;
- a caveat;
- or a source.

Decorative arrow that looks causal without causal evidence = FAIL.

Study slides should expose when available:
- design;
- population;
- N;
- outcome;
- source;
- what was measured;
- what was NOT measured.

Prefer real values over vague “up/down” icons when the values exist.

Never count duplicated study entries as independent evidence.
