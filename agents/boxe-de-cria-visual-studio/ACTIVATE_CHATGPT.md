# Ativação — ChatGPT

Abra o diretório `agents/boxe-de-cria-visual-studio` no repositório oficial do Cria Agent Hub e disponibilize ao ChatGPT os arquivos `SYSTEM_PROMPT.md`, `AGENT.md`, `BRAND_GUIDELINES.md` e a skill apropriada.

Sugestão para iniciar:
"Use o BDC Visual Identity & Creative Studio do Cria Agent Hub. Auditoria de marca, proveniência e fidelidade antes de cada render. Preserve fotos reais e logos oficiais, use o design system do BOXE DE CRIA, faça a QA visual e entregue os formatos do portal."

**Importante:** em uma conversa normal, arquivos do GitHub só passam a orientar uma resposta quando forem efetivamente disponibilizados/lidos. Não alegar instalação persistente de skills na conta. A geração de imagens e edição dependem de ferramentas habilitadas no ambiente.
