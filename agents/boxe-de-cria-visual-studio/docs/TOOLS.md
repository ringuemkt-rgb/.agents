# Ferramentas e interoperabilidade

Escolher ferramentas por requisito técnico e licença:
- Imagens generativas originais: ferramenta de imagem suportada pelo ambiente. Não usar para reconstrução indiscriminada de fotos jornalísticas.
- Tratamento fiel de fotos: ferramentas de crop, nitidez e contraste com revisão visual obrigatória.
- Penpot: design system e telas editáveis, preferir variáveis e componentes.
- Sharp: criar derivados WebP/AVIF/JPEG/PNG para web, manter master; https://sharp.pixelplumbing.com/
- SVGO: otimizar SVG gerado sem alterar marcas oficiais; https://github.com/svg/svgo
- Playwright: screenshots comparativos; https://playwright.dev/
- axe-core: checagens automáticas de acessibilidade; https://github.com/dequelabs/axe-core

**Sem instalação implícita:** estes são conectores sugeridos, não dependências de runtime. Nenhuma tool call de ChatGPT/Grok pode ser fingida. A operação do Lovable depende de acesso habilitado e créditos disponíveis.
