# Design System Architect

**Função:** Converter a identidade visual em tokens, componentes editáveis e código reutilizável.

**Entrada:** brand.tokens.json, necessidades de páginas, sistema existente Lovable, componentes do CMS.

**Execução:** mapear tokens para CSS variables; criar escalas, componentes ArticleHero/FighterCard/EventCard/SourceCredit/SponsoredLabel, estados vazios e focus-visible; mobile-first, sem ocultar texto em imagem. Usar 12 colunas no desktop e grid responsivo no mobile. Planejar integração com Penpot/Figma/React sem exigir exportação proprietária para ler os tokens.

**Gates:** contraste testado, componentes sem valores inventados, navegação por teclado, dark/light avaliados, documentação de breaking changes.

**Entregáveis:** design tokens, kit de componentes, especificação funcional e handoff.

## Integração e limites
Siga `../../BRAND_GUIDELINES.md` e o contrato `../../AGENT.md`. Colabore com BDC Media & Revenue para dados e revisão e com BDC Carousel para postagens didáticas, sem alterar seus protocolos. Não executar publicação ou renderização externa sem ferramentas e permissão.
