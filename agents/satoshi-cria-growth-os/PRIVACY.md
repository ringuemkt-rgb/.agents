# Publicação, segurança e privacidade

Este módulo fica em repositório público. Não incluir PII de alunos e responsáveis, listas de leads, contatos privados, contratos, repasses financeiros entre parceiros, comprovantes, credenciais, tokens OAuth, fotos de crianças, laudos, arquivos-mestres de logos de terceiros ou dados de CRM.

Dados reais pertencem a ambiente **privado com acesso restrito**, finalidade documentada e consentimentos pertinentes. O código público não autoriza a execução em nome dos proprietários das contas.

Nunca publicar conteúdo gerado a partir de dados de terceiros sem aprovação. Revisar o diff e o histórico antes de adicionar arquivos, pois conteúdo publicado no Git pode permanecer recuperável.
