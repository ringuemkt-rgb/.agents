# Template — Pedido de carrossel

Copie e preencha este pedido em qualquer chat de IA ativado com o sistema.

---

```text
Crie um carrossel completo para a marca Cane Corso do Cangaço.

TEMA:
{tema do carrossel}

OBJETIVO:
{educar, viralizar, gerar direct, gerar salvamento, vender lista de espera, combater mito etc.}

PÚBLICO-ALVO:
{tutores, compradores, praticantes de jiu-jitsu, famílias, criadores, curiosos etc.}

DOR PRINCIPAL:
{qual problema o público sente?}

CRENÇA ERRADA A QUEBRAR:
{qual mito ou erro será atacado?}

NÍVEL DE PROFUNDIDADE:
{iniciante / intermediário / técnico}

FORMATO:
{8 slides / 10 slides / post único / Reels}

EXIGÊNCIAS:
- seguir o Cane Corso do Cangaço Prompt Production OS;
- gerar roteiro slide por slide;
- gerar texto exato de cada slide;
- gerar prompts individuais e autônomos;
- criar legenda final com emojis e CTA;
- criar Reels derivado;
- criar Stories derivados;
- terminar com 5 temas com maior potencial viral e IPV estimado.
```

## Exemplo preenchido

```text
Crie um carrossel completo para a marca Cane Corso do Cangaço.

TEMA:
Socialização correta do filhote Cane Corso.

OBJETIVO:
Gerar salvamento e educar compradores/tutores.

PÚBLICO-ALVO:
Tutores de filhote e pessoas que querem comprar um Cane Corso.

DOR PRINCIPAL:
Medo de criar um cão reativo ou instável.

CRENÇA ERRADA A QUEBRAR:
Socializar é soltar o filhote no mundo.

NÍVEL DE PROFUNDIDADE:
Intermediário, linguagem clara.

FORMATO:
8 slides.

EXIGÊNCIAS:
- seguir o Cane Corso do Cangaço Prompt Production OS;
- gerar roteiro slide por slide;
- gerar texto exato de cada slide;
- gerar prompts individuais e autônomos;
- criar legenda final com emojis e CTA;
- criar Reels derivado;
- criar Stories derivados;
- terminar com 5 temas com maior potencial viral e IPV estimado.
```
