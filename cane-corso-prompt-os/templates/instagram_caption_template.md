#canecorso #canecorsobrasil #canecorsodocangaco #criacaoresponsavel #guardiaodefamilia

---

## CTAs por objetivo

### Para salvamento

```text
📌 Salve este post antes de escolher seu filhote.
```

### Para compartilhamento

```text
📤 Envie para quem acha que Cane Corso bom é Cane Corso bravo.
```

### Para comentário

```text
👉 Comente FILHOTE para receber o checklist.
```

### Para direct

```text
📩 Mande LISTA no direct para entrar no processo.
```

## Hashtags-base

```text
#canecorso #canecorsobrasil #canecorsodocangaco #criacaoresponsavel #guardiaodefamilia
```

Use poucas hashtags e mantenha relevância. Não encha a legenda com hashtags genéricas sem função.
