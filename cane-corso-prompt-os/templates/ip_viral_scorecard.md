# Template — IPV: Índice de Potencial Viral

O IPV é uma estimativa estratégica para priorizar temas. Não é garantia matemática de viralização.

---

## Pesos

| Critério | Peso |
|---|---:|
| Dor real do público | 20 |
| Potencial de compartilhamento | 15 |
| Potencial de salvamento | 15 |
| Força do gancho | 15 |
| Aderência à marca | 10 |
| Busca social / interesse recorrente | 10 |
| Prova técnica disponível | 5 |
| Capacidade de gerar comentário | 5 |
| Segurança para recomendação | 5 |

---

## Interpretação

| IPV | Leitura |
|---:|---|
| 90–100 | prioridade máxima |
| 80–89 | alto potencial |
| 70–79 | bom potencial |
| 60–69 | usar com ajuste de gancho |
| abaixo de 60 | não priorizar agora |

## Métricas principais possíveis

- salvamento;
- compartilhamento;
- comentário;
- direct;
- lead;
- autoridade;
- alcance;
- retenção.

---

## Exemplo

```text
1. Tema: Cane Corso não é cão bravo. É cão equilibrado.
IPV estimado: 94%
Métrica principal: compartilhamento + comentário
Nível de evidência: alto
Por que fazer: quebra uma crença popular forte, protege a marca contra público errado e gera identificação com tutores responsáveis.
Gancho sugerido: “Cane Corso bom não é o mais bravo.”
Prioridade: máxima
```
